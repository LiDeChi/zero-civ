# 世界 v0：季风河谷

`framework.md` 讲的是系统怎么搭，本文讲世界本身：它长什么样、关于什么、受什么约束。

---

## 1. 原则：设定问题，不设定答案

世界必须“关于”某件事，否则就是一锅看不懂的汤。但如果设定的是内容（部落、国王、语言模块），发生的一切就只是剧本。

所以这里只设定**世界向居民提出的问题**，也就是一组压力。怎么回应这些压力，比如合作、说话、修东西、分工，由居民自己长出来。

约束不是涌现的对立面，而是它的来源。没有约束的世界里，最简单的东西就够活，什么也不会长出来。

---

## 2. 世界关于什么

> **在一个会变、看不全、一个人扛不住的世界里活下去：靠彼此，也靠前人留下的东西。**

这句话里有四种压力，每一种都对应一类可能长出来的东西：

| 压力 | 世界里的具体形式 | 可能逼出来的东西 |
| --- | --- | --- |
| 会变 | 季风不规则，河道会涨落、改道，果实按季节和地区轮流成熟 | 预测、记忆、迁徙、储存 |
| 看不全 | 视野只有几格，夜里更短；资源分散，常在视野之外 | 信号、谈论不在场的东西、侦察分工 |
| 一个人扛不住 | 大型猎物要几个个体同时围住；修堤要很多劳动 | 共同利益、真诚的信号、协调、组织 |
| 前人留下的东西 | 地形改造和地面记号都会持久存在，一直留给后代 | 文字、技术、外部记忆、历史的棘轮 |

---

## 3. 世界长什么样

一张俯视的 2D 地图，v0 大约 128×128 格。

- **地形**：西北是高地，一条大河向东南流入海，把陆地切成几块。两岸有冲积平原、湿地、干坡，还有几条支流。
- **水**：按地形高度流动。雨季涨水，平原会被淹；旱季退水，出现可以涉水过河的浅滩。
- **植物**：需要水才能生长，季节性结果。采得太狠会衰退，恢复很慢。
- **动物**：两类，都按简单规则运动。小型动物一个居民就能抓到；大型兽群会随季节迁徙，必须两三个居民同时围住才能捕获，但回报大得多。
- **材料**：泥、石、木，可以搬运，用来堆高、筑堤、刻记号、搭桥。
- **居民**：地图上的小点，颜色表示谱系或群体。发出的信号显示为涟漪加符号，地面记号显示为小字形。

给人看的画面，大致是一张极简版的 Dwarf Fortress 或 RimWorld 地图，可以快进、回放、分叉。地名、族群名、个体名由 LLM 在编年史里起。

### 为什么选河谷

- **水流本身就是“规则即物质”。** 地形高度决定水往哪流、哪里能走、哪里长东西。居民挖沟、堆堤，就是在改写局部物理，而且改造的后果会持久留给后代，比如灌溉、防洪，或者一条堤毁了下游。
- **河流既隔离又连接。** 两岸的群体平时分开，会分化出方言；旱季的浅滩和后来搭的桥又让它们接触。语言接触、交易、冲突都有了舞台。
- **人有直觉。** 两河、尼罗河、黄河，文明从河谷里长出来，人看得懂这种故事，比如“第一次修堤”“大旱年两岸相遇”。

考虑过但没选的：

- **抽象化学汤、纯 Lenia**：离语言太远，人也读不懂。
- **群岛**：隔离太强，接触太少。
- **开放平原**：没有隔离，不容易分化出方言，也缺少可改造的地形。

## 4. 居民

### 身体

位置、能量、水分、年龄，一次最多携带一件东西。寿命有限，大约相当于十几个季节。

繁殖需要能量达到阈值，并且有一个相邻的伴侣。选择伴侣这件事，会让谱系和社会结构更丰富。

### 感知

- **视觉**：半径约 5 格，夜里缩短。
- **听觉**：附近的信号。
- **触觉**：脚下的地面记号。
- **自身状态**：能量、水分、年龄、携带物。

### 心智

一个小型循环神经网络，隐藏状态就是跨时间的记忆。

心智参数随繁殖遗传并突变。v0 之后可以加入**幼年期模仿学习**：幼年只有很短的学习窗口，只能观察到有限的样本。这就是代际学习瓶颈，它会逼出组合性。

### 动作

每个动作都要付能量。

| 动作 | 说明 |
| --- | --- |
| 移动 | 代价取决于地形高度差、是否有水 |
| 吃、喝 | 能量和水分的唯一来源 |
| 拾起、放下 | 搬运材料和食物 |
| 挖、堆 | 改变地形高度，从而改变水流和移动代价；泥土守恒，挖出来的要放在别处 |
| 发声 | 从一个小词表（比如 8 到 16 个符号）里发出一个符号，附近能听到，很快消散 |
| 刻记号 | 在地面留下一个持久符号，别人经过能读到，可以被擦掉或覆盖 |
| 给予 | 把携带物或一部分能量交给相邻个体 |

### 世界里没有什么

没有“语言模块”，没有“部落”“首领”“职业”这类对象，也没有奖励函数。符号一开始没有任何意义。群体、角色、词义、制度，如果出现，都是涌现出来的，由观测层去识别。

居民的唯一“目标”是隐含的：活不下去、生不出后代的心智会消失。

## 5. 约束：三层

### 第一层：物理约束（kernel，永远不改）

- **能量守恒**：能量只能从植物和动物那里来，所有动作都消耗能量。
- **物质守恒**：泥土、石头、水不会凭空出现或消失，只会被移动。
- **局部性**：只能感知和作用于附近；信号和移动都有速度上限。
- **成本**：每一次移动、发声、刻写、挖掘都要付费。

这一层保证世界里没有作弊，也保证规律稳定，可以被居民和 LLM 发现。

### 第二层：世界设定（运行前调好，运行中不改）

地形生成方式、气候规律、植物和动物的种类及参数、寿命、视野半径、词表大小、各动作的代价。

这一层决定世界“关于什么”。换一套设定，就是另一个世界，比如去掉大型猎物，合作压力就会消失。调参的目标是让世界处在**“勉强能活”**的区间：太宽松，最简单的策略就够了；太严苛，种群直接灭绝。

总中介的环境杠杆（天气、灾害、投放资源）只能在这一层允许的范围内活动，比如让某一年旱一点，但不能凭空造出一种新的物理。

### 第三层：给我们自己的设计约束

- **人要看得懂**：对象种类少，每种都有直观的样子，每种现象都能被观测层检测到。
- **算得起**：用 JAX 在单张 GPU 上跑几千个居民，一次运行要能看到几百代。
- **不写剧本**：不预设任何社会结构或语义。
- **可回放、可分叉**：世界状态完全可以序列化，随机数可以复现。

### 不受约束的部分

居民去哪、做什么、和谁合作、符号是什么意思、在哪修什么、怎么组织：这些都不受约束，而这就是涌现发生的地方。

## 6. 一段可能发生的历史（示意，不是剧本）

下面这段只是用来说明这个世界能讲出什么样的故事，实际发生什么由世界决定。

> 旱季，河东的果树大多枯了。几个个体往上游走，找到一片还有果子的湿地。其中一个来回奔波，每次回到同伴身边都发出某个符号，之后同伴跟着它往上游走。
>
> 几代以后，这个符号在河东稳定地出现在“上游有食物”的情境里，河西却没有这个用法，河西有自己的一套符号。
>
> 某年大旱，河水退得比往年都低，两岸的群体第一次在上游的浅滩相遇……
>
> 再往后，有一群开始在浅滩边堆石头，雨季过后，那里的水位比别处高，植物也长得更好。这道石堆留了下来，后来的个体一出生，就生活在一个有“堤”的世界里。

这段话里的每一件事，都对应一个可以测的指标：符号的因果影响、方言分化、群体接触、地形改造的持久性和收益、改造对后代的影响。

## 7. 按阶段开放

世界不是一次把所有东西都打开，而是和路线图同步，一层一层加：

| 阶段 | 新开放的东西 | 要验证什么 |
| --- | --- | --- |
| v0.0 | 地形、水、季风、植物、居民的移动和吃喝、繁殖 | 种群能在“勉强能活”的区间长期维持，行为出现分化 |
| v0.1 | 小型动物、大型兽群（需要协作捕获）、给予 | 是否出现稳定的协作捕猎 |
| v0.2 | 发声 | 信号是否有正的因果影响，关掉以后集体表现是否下降 |
| v0.3 | 刻记号 | 持久记号是否被使用；可擦写和不可擦写的对照 |
| v0.4 | 挖、堆、材料搬运 | 地形改造是否出现、是否持久、是否让后代受益 |
| v0.5 | 幼年模仿学习 | 是否出现文化传递和方言分化 |

使者和接应者在 v0.2 之后才有意义，因为在那之前，世界里还没有可以用来交流的通道。

---

## 8. 还没定的

- 繁殖要不要伴侣：有伴侣更丰富，无性繁殖更简单。v0.0 可以先用无性繁殖。
- 发声用离散符号还是连续向量：离散的更容易被人和 LLM 读懂，所以先用离散的。
- 是否加入捕食者：能增加危险和对警报信号的需求，但会让调参变难。
- 一个季节多少步、一次运行多少季节：要等 v0.0 跑起来，根据速度再定。
