# zero-civ 研究框架

> 一个会自己长出东西的数字世界，一串有立场的代理层把它翻译给人看，人的回应再经由这些代理层，以受约束的方式回到世界里。历史从不清零。

本文把前期讨论收拢成一个框架：要做什么、不做什么、系统由哪些部分组成、哪些原则不能破、怎么判断成功、先做什么。

---

## 0. 一句话定位

**做一个能产生历史的数字世界：世界自己涌现，LLM 作为多层中介去观察、策展、呈现，并在约束下反向影响世界，为下一次呈现做铺垫；人通过这些中介与世界打交道，而每一次交互都进入世界的因果链。**

它和相邻的东西的区别：

| 相邻的东西 | 区别在哪 |
| --- | --- |
| 人工生命 / 元胞自动机 | 不止于复杂图案，要有可读的历史，并和人形成闭环 |
| 用 AI 生成游戏世界 | 世界不是每次重新生成的，内容由世界自己长出来，后果不被 reset |
| LLM 智能体小镇 | 世界的主角不是 LLM，而是涌现出来的居民；LLM 只做薄的中介层 |
| Coding agent 改代码 | 不接受“根据要求改世界”，干预只能走世界内部的杠杆，并承担长期后果 |

**当下的主题**：这个系统的结构（人只能通过 AI 中介看世界、影响世界，中介之下是层层代理和一个复杂的世界）正是现实正在变成的样子。所以它可以作为“AI 中介时代的缩微模型”：在一个我们掌握全部真相、可以分叉的世界里，研究中介会不会扭曲真相、委托链越长人还能否掌舵、陌生的机器语言能否被翻译和监督等问题。详见 [questions.md](questions.md)。

**三种形态**：同一个内核可以做成实验、游戏或游戏框架，优化目标不同，取舍也不同。当前建议以游戏为主形态：先做一个游戏，再从中抽出框架，实验保留为游戏里的一种模式。详见 [game.md](game.md)。

## 1. 这个框架是怎么来的：几次关键收敛

这一节记录思路是怎么走到现在的，方便以后回头判断某个决定还成不成立。

1. **从“cell 够不够复杂”到“规则由谁决定”。** 简单规则就能做通用计算，状态复杂度不是瓶颈。瓶颈是规则躲在世界外面，生命碰不到。
2. **把外部参数搬进世界。** 更新频率、扩散速度、感知范围、通信方式、局部算子参数，都可以变成世界里的状态，于是它们变成可竞争、可演化的资源。
3. **规则即物质，而不是规则和物质之间的双射。** 规则以物质的形式存在，可被复制、组合、改写，并且任意状态都能被执行。外面只留一个小而冻结的 kernel。
4. **放弃“让生命改真正的代码”。** 自由度不是瓶颈，真正稀缺的是积累。而且稳定的底层物理是“规律可被发现”的前提，对世界里的居民和世界外的 LLM 都成立。
5. **奖励来自资源经济，而不是 reward function。** 更好的感知、预测、协调，会真实地换来更多持续存在的机会。
6. **目的从“让生命改世界”收敛到“让世界长出东西，并让人能接触它”。** 语言、文明、技术是世界**可能长出来的内容**，不是系统的定义。
7. **LLM 的位置从“世界里的高层智能”挪到“世界和人之间的中介”。** 它的任务是理解和转达，而不是替世界思考。
8. **单层中介扩展成多层代理。** 好玩和启发都出在层与层之间的缝隙里：翻译、筛选、误解、立场。

## 2. 系统全景：五层加三条基础设施

```
            ┌──────────────────────────────────────┐
  人        │ 看、追问、选择、停留、表达意图        │
            └───────────────▲──────────┬───────────┘
                     呈现   │          │ 反应
            ┌───────────────┴──────────▼───────────┐
  总中介    │ LLM（世界外）：策展人 / 叙事者 / 科学家│
            │ 读观测层，写编年史，提假设，选干预     │
            └───────────────▲──────────┬───────────┘
                     报告   │          │ 指令（有带宽限制）
            ┌───────────────┴──────────▼───────────┐
  使者      │ LLM 化身（世界内）：有身体、局部视野、  │
            │ 行动付费、有自己的立场和利益           │
            └───────────────▲──────────┬───────────┘
                     信号   │          │ 信号 / 物质
            ┌───────────────┴──────────▼───────────┐
  接应者    │ 涌现出来的、专门与使者打交道的居民      │
            │（不设计，只创造让它们出现的条件）       │
            └───────────────▲──────────┬───────────┘
            ┌───────────────┴──────────▼───────────┐
  居民+物理 │ 神经网络居民、资源、信号、人工物、      │
            │ 可改写的局部物理参数；kernel 冻结       │
            └──────────────────────────────────────┘

  基础设施：① 观测层  ② 干预接口  ③ 历史存储（事件日志 + 快照 + 分叉）
```

### 2.1 每一层的职责和边界

| 层 | 能做 | 不能做 |
| --- | --- | --- |
| kernel | 解释规则物质、执行守恒、结算成本、保证局部性 | 被任何层修改 |
| 居民 | 感知局部、行动、发信号、留下人工物、改写附近的物理参数、繁殖、学习 | 凭空产生资源 |
| 接应者 | 就是居民，只是在交流网络里占据了特殊位置 | 由设计者指定 |
| 使者 | 在世界里移动、发信号、放物质，向总中介汇报 | 读全局状态、直接改居民的心智或行为、免费行动 |
| 总中介 | 读观测层、写编年史、给使者下指令、使用受限的环境杠杆、生成呈现 | 直接改世界状态、超出干预预算 |
| 人 | 看、追问、选择、表达意图 | 绕过中介直接操纵世界（实验模式下的分叉除外） |

### 2.2 三条基础设施

- **观测层**：把原始状态变成可读的东西。包括个体和谱系追踪、群体聚类、事件检测（出生、死亡、迁徙、冲突、新信号出现）、信号与情境的统计、新颖性检测。**这一层往往比 LLM 本身更难也更重要**，LLM 直接读格子是读不出东西的。
- **干预接口**：一组有限、付费、全部记录的杠杆（天气、资源分布、灾害、投放新物质、使者的行动）。
- **历史存储**：全量事件日志、周期快照、git 式分叉。它同时服务于回放、反事实实验、对照世界和“向下追查是哪一层出了偏差”。

## 3. 不能破的原则

这些是框架的“宪法”。某个设计违反了其中一条，就要么改设计，要么明确记录为什么破例。

1. **kernel 冻结，而且要小。** 只做三件事：局部性（信息传播有速度上限）、守恒（能量和计算预算守恒）、成本（每一次更新、感知、写规则、发信号都要付费）。
2. **规则即物质，并且有一条可修改性梯度。** kernel 不可改；局部物理参数是物质，可以付费改写；更高层的“规则”由居民造出来的结构实现（墙、通道、膜、网络）。
3. **历史不清零。** 世界永不重置。实验靠分叉，不靠重来。
4. **世界不写剧本。** 世界只遵守物理，内容由世界自己决定。好看靠策展，不靠创作。
5. **LLM 只能走世界内部的通道。** 总中介只能动环境条件，使者只能用和居民同样付费的方式行动。能改变的是条件，结果由世界决定。
6. **干预有预算、可追溯、有对照。** 每轮干预次数和强度有限；每条消息在每一层的原文和转述都存档；始终保留一个从同一时刻分叉、不受干预的对照世界。
7. **LLM 层越往下越薄。** 使者数量少、行动贵、受物理约束。舞台主体留给涌现出来的居民，否则故事会变成 LLM 角色之间的戏。
8. **每一层都有真实的自主性和利益，层间带宽有限。** 没有利益就没有立场，没有瓶颈就没有取舍，多层就退化成流水线。
9. **LLM 的解读必须能被干预验证。** 翻译要变成可检验的预测（“发出这个信号，它们会做 X”），然后真去做实验。

## 4. 核心概念的工作定义

先给出可操作的定义，够用就行，以后可以改。

### 4.1 主体

有跨时间的内部状态，并且用这个状态改变自己未来的行为：它会预测，然后行动。稳定的涡旋不算。

可测量的替代指标：个体性的信息论度量（Krakauer 等），以及 empowerment（行动和未来状态之间的信道容量）。

### 4.2 因果干预的四个层级（技术的阶梯）

| 层级 | 含义 | 在本世界里对应什么 |
| --- | --- | --- |
| 1. 推断 | 通过观察和实验归纳规律 | 居民的学习；LLM 的科学工作 |
| 2. 使用可编程结构 | 利用世界里已有的、能改变其他东西动力学的结构 | 利用别人留下的墙、通道、人工物 |
| 3. 读取规则 | 直接感知规律的表示 | 感知附近格子的物理参数 |
| 4. 改写规则 | 付费改写规律的表示 | 改写附近格子的物理参数 |

足够持久、并约束了其他东西动力学的“事物”，对别的东西来说就是“规则”。所以“出现新事物”和“修改规则”是同一条梯度上的不同位置。

### 4.3 语言：四层判定

语言是一种**在“对方能用”约束下的有损压缩**。纯压缩的终点是一个词代表一切，必须同时存在交流压力才会出现结构。

| 层 | 判定 | 测法 |
| --- | --- | --- |
| 1. 被真正使用 | 信号改变了接收者的行为和结果 | 干预信号，测 CIC（causal influence of communication） |
| 2. 有语言特征 | 约定性、组合性、位移性、文化传递 | 方言分化；对新组合的泛化；信号和不在场事物相关；打乱映射后需重新学习 |
| 3. 带来功能提升 | 个体和集体决策变好 | 关掉私人通道测个体；关掉公共通道测集体；只让高中心度个体失语，对比随机失语（“文盲统治者”实验） |
| 4. 载体与使用者协同演化 | 信号系统和人工物本身被优化 | 在复杂度-信息量平面上逼近最优前沿；人工物谱系深度；新一代学会语言的速度 |

结论分级：1+3 成立算“有功能的通信技术”；再加 2 算“语言”；再加 4 算“会演化的语言文化”。

只满足你最初那个功能性标准（个体和集体因可感知的信号而提升，信号也被优化）的，是更宽泛的“信息技术”，蚂蚁的信息素路径和道路也在其中。语言是它的子集，区分点正是约定性、组合性和位移性。

### 4.4 历史与棘轮

“能产生历史”可以直接测：

- 抹掉第 N 代留下的环境改造、只保留居民，看后代表现；
- 保留环境改造、换成未经演化的居民，看后代表现。

两者的差异就是**环境作为外部记忆的贡献**，对应文化演化里的棘轮效应。

## 5. 世界设计：分两步走

### 5.1 路线选择

| | 路线 B | 路线 C |
| --- | --- | --- |
| 主体是什么 | 模拟器里的一等对象，身体是固定的数据结构 | 世界物质构成的一团，核心携带神经网络 |
| 身体、工具、环境 | 不同类型的对象 | 同一种物质，彼此连续 |
| 成本 | 便宜，能跑几千个体、几万代 | 贵得多，还要解决“分裂后心智跟谁走” |
| 适合研究 | 语言、社会、中介循环 | 身体与技术的连续体 |

**决定：先 B 后 C。** 心智、感知和通信接口设计成两边通用，迁移时只换身体的表示。

### 5.2 世界 v0：季风河谷

具体设定见 [world.md](world.md)。概要：

- **关于什么**：在一个会变、看不全、一个人扛不住的世界里活下去，靠彼此，也靠前人留下的东西。
- **长什么样**：俯视的河谷地图，季风不规则，河流隔开几块陆地，旱季出现浅滩。
- **规则即物质**：地形高度决定水流和移动代价，居民可以挖和堆，改造会持久留给后代。
- **信号和文字**：即时、付费、会消散的发声（口语）；持久、可擦写的地面记号（文字）。
- **约束分三层**：物理（kernel，永不改）、世界设定（运行前调好）、给我们自己的设计约束。

时钟预算（更新频率作为资源）不放进 v0，留在并行的小研究线里验证。

### 5.3 让语言有机会出现的条件

这些条件要写进世界设计和资源经济里，而不是写进奖励：

- 部分可观测，加上共同利益（合作时传递真实信息才有好处）；
- 信息不对称（一方看得到、另一方看不到）；
- 信号有成本（逼出压缩）；
- 代际学习瓶颈（逼出组合性）；
- 持久、可修改的人工物（文字）；
- 角色异质性和网络位置差异（关键节点才可能出现）。

### 5.4 让接应者有机会出现的条件

接应者不能设计，只能创造条件：与使者打交道要**真的**能带来好处（资源、信息优势），同时要有成本和门槛，这样才会分化出专门做这件事的个体，而不是人人都做。

## 6. 中介循环

### 6.1 一轮循环

1. **采集**：世界运行，观测层产出结构化事件流，总中介和使者各自读取自己权限内的部分。
2. **向上汇报**：接应者用信号“讲给”使者；使者带着自己的立场写成有长度限制的报告。
3. **策展与呈现**：总中介从报告和观测数据里挑出值得看的东西，整理成人能看懂、会在乎的形式。
4. **人的反应**：看了什么、停在哪、追问了什么、表达了什么意图。
5. **提出问题**：总中介据此推测下一次值得呈现什么，并把它写成一个可以检验的问题（例如：“河边这两群遇上干旱，会冲突还是合作？”）。
6. **向下干预**：通过环境杠杆或给使者下指令，改变条件，不改变结果。同时从当前时刻分叉出对照世界。
7. 世界带着干预继续演化，回到第 1 步。

第 5、6 步让“为下一次呈现做铺垫”同时成为一次因果实验：对人来说是有悬念的故事，对研究来说是有对照的干预。

### 6.2 三扇窗

| 窗口 | 内容 | 服务于 |
| --- | --- | --- |
| 编年史 | 谱系图、时间线、LLM 写的新闻和纪录片、有名字的个体和族群 | 可读、让人在乎 |
| 实验室 | 分叉、改条件、对比历史、LLM 科学顾问给出假设和证据 | 启发性 |
| 接触 | 通过使者发信号、放物质，LLM 协助破译回应，可以逐层追查信息在哪里变了形 | 参与感，人的影响进入历史 |

### 6.3 人的角色

博物学家（观察、命名）、园丁或气候之神（有限、付费的环境干预）、第一次接触的使者（学会一门真正涌现出来的陌生语言，并用它达成某件事）。第三种最能体现这个项目的独特性。

## 7. 衡量指标

| 类别 | 指标 |
| --- | --- |
| 涌现 | 个体性度量；基础模型嵌入空间的新颖性和多样性（参考 ASAL）；开放式演化是否停滞 |
| 主体与技术 | empowerment 随时间的增长；物理参数改写的频率、持久性和收益 |
| 语言 | 第 4.3 节的四层判定 |
| 历史 | 第 4.4 节的棘轮对照；人工物谱系深度（可改 vs 不可改） |
| 中介 | 翻译的预测准确率；干预世界和对照世界的差异；自发事件与干预后事件在呈现中的占比 |
| 人 | 会不会自己回来看（娱乐性）；离开时对某个问题的看法有没有变（启发性） |
| 健康度 | 守恒测试始终通过；没有“作弊式物理”占满世界；LLM 角色没有喧宾夺主 |

## 8. 路线图

原则：**先让一个完整的循环跑起来，再逐步加厚每一层。** 每个阶段都预先写下一个可证伪的小结论。

### 阶段 0：基座

- 用 JAX 实现世界 v0（第 5.2 节），GPU 上跑。
- kernel 的守恒测试和成本结算测试先写好。
- 事件日志、快照、分叉从第一天就有。
- **可证伪结论**：在非平稳环境下，居民种群能长期维持，且行为策略出现分化，而不是收敛到单一的最简策略。

### 阶段 1：观测层和编年史

- 个体、谱系、群体追踪，事件检测，结构化事件流。
- 总中介只做采集和呈现，产出编年史窗口。
- **可证伪结论**：LLM 能从世界里持续挑出人觉得有意思的事件；它的叙述能被观测数据核实（不编造）。

### 阶段 2：干预与对照

- 环境杠杆、干预预算、自动分叉对照世界。
- 总中介开始“提出问题、施加干预、呈现结果”。
- **可证伪结论**：带铺垫的呈现比不带铺垫的更受人关注，同时干预世界和对照世界在涌现指标上没有退化成剧本（新颖性不下降、结局不可由 LLM 预先确定）。

### 阶段 3：信号与文字

- 开放信号通道和人工物；做可改写 vs 不可改写的对照。
- 跑语言四层判定的第 1、3 层。
- **可证伪结论**：信号有正的 CIC，关掉信号通道会使集体觅食或避险表现显著下降；可改写人工物比不可改写的产生更深的谱系。

### 阶段 4：使者和多层代理

- 先一个使者，跑通人 → 总中介 → 使者 → 居民的双向链。
- 再多个立场不同的使者，观察分歧和汇报差异。
- 接触窗口上线，翻译以预测准确率计分。
- **可证伪结论**：使者对当地信号的翻译，预测准确率显著高于基线；同一事件在不同使者汇报中的差异可以追溯到它们各自的立场。

### 阶段 5：接应者和规则物质

- 创造接应者出现的条件（第 5.4 节），做“只让接应者失语”的实验。
- 扩大可改写的物理参数范围，观察居民改造局部物理的行为。
- **可证伪结论**：出现了与使者交互高度集中的个体，让它们失语造成的集体损失显著大于随机失语。

### 阶段 6：迁移到路线 C

- 身体由世界物质构成，研究身体、工具、环境的连续体，以及远程通道（有建设和维护成本的高速链路）是否会自发出现。

### 并行的小研究线

**时间尺度作为资源**：Flow-Lenia 加时钟预算加守恒，只开放更新频率一个自由度，看是否出现稳定共存的快慢两种策略。它独立于主线，结果可以反哺世界 v0 的时钟预算设计。

## 9. 风险与对策

| 风险 | 对策 |
| --- | --- |
| 开放式演化停滞 | 非平稳环境、协同演化、按阶段放开新的自由度 |
| 可改规则导致作弊式物理 | 守恒律是生命线，守恒测试先于一切功能 |
| 观测层做不好，LLM 读不懂世界 | 把观测层当作一等工程，和世界同步迭代 |
| LLM 编造或过度解读 | 叙述必须可被观测数据核实；翻译必须可被干预验证 |
| 干预把涌现变成剧本 | 只动条件不动结果、干预预算、对照世界、呈现中标注自发与干预 |
| LLM 角色喧宾夺主 | 使者少、贵、受物理约束；监控 LLM 相关事件在呈现中的占比 |
| 为吸引注意力而演化（Goodhart） | 人的反应先只影响中介的选题，不直接变成世界里的资源；如果以后接入资源注入，把它当作被研究的现象而不是目标 |
| 算力不够 | 路线 B 起步，规则小而同构，尽早 GPU 化 |
| 叙事跑在结果前面 | 每阶段预先写下可证伪结论，未通过不进入下一阶段 |

## 10. 待定的决策

这些问题现在不必定死，但到了对应阶段需要明确选择：

1. **居民怎么学习**：纯神经演化，还是演化加终生学习（强化学习或预测学习）？后者对语言的文化传递更有利，但更贵。
2. **人的反应是否直接进入世界**：只影响中介选题，还是也转化为世界里的资源注入？
3. **使者的利益如何定义**：绑定驻地族群的状况，还是有独立的能量账户？
4. **总中介的干预预算**：固定配额，还是由人的参与度动态决定？
5. **世界的时间尺度和人的时间尺度怎么对齐**：离线期间世界跑多快，回来时呈现多少？
6. **规则物质的形式**：只用参数型，还是某些物质携带小型程序去读写参数？
7. **中介的目标**：追求关注度、追求准确度、服从人明确表达的目标，还是混合？按 [questions.md](questions.md) 的建议，这应当作为实验变量，而不是一次定死。
