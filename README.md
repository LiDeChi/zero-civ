# zero-civ

一个能产生历史的数字世界：世界自己涌现，LLM 作为多层中介去观察、策展、呈现，并在约束下反向影响世界；人通过这些中介与世界打交道，每一次交互都进入世界的因果链。

- [研究框架](docs/framework.md)：定位、系统分层、设计原则、核心概念、指标、路线图、风险
- [世界 v0：季风河谷](docs/world.md)：世界长什么样、关于什么、受什么约束
- [当下的问题](docs/questions.md)：这个世界能帮人回答哪些现在就有人在乎的问题
- [实验、游戏、游戏框架](docs/game.md)：同一个内核的三种形态，以及为什么建议先做游戏
